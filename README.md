# Akshama Chauhan – Portfolio

Personal portfolio: IoT, full-stack and GenAI projects.
Single-file static site (`index.html`) – no build step.

## Deploy on GitHub Pages
1. Create a new public repo named `Akshama2003.github.io` (or any name, e.g. `portfolio`).
2. Upload `index.html` and this `README.md` to the repo root.
3. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / root → Save.
4. Live in ~1 minute at `https://akshama2003.github.io/` (or `/portfolio/` for a differently named repo).
